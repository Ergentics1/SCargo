# Code of Conduct

## Our Pledge

We pledge to make participation in SCargo a respectful, welcoming, and harassment-free experience for everyone, regardless of background or experience level.

## Expected Behavior

- Communicate clearly, respectfully, and constructively.
- Focus critique on technical accuracy, verifiable evidence, and reproducible results.
- Give credit to primary sources and fellow contributors accurately.
- Respect project boundaries, security reporting rules, and code-data separation standards.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or discriminatory language.
- Publishing private information, credentials, or personal data without permission.
- Deliberately introducing backdoors, falsified measurements, or suppressed test failures.

## Enforcement

Project maintainers may edit, reject, or remove comments, commits, issues, or pull requests that violate this Code of Conduct. Reports can be raised privately via GitHub Security Advisories or directly with repository maintainers.
