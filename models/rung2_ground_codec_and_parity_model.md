## 1. Shared Ground-Level Data Model & Canonical Codec

Every compartment independently implements the exact same canonical schema for proof-repository structural analysis (pre-requisite to Rung 3 proof reduction):

1. **`GroundModule`**:
   - `name`: canonical dotted module identifier (unique across graph)
   - `lines`: nonnegative source line count
   - `bytes`: nonnegative source byte count
   - `imports`: list of direct module dependencies (canonicalized by sorting & deduplicating without altering reachability)
   - `wrapper_kind`: `pure_wrapper` | `reexport_hub` | `substantive`
2. **`GroundGraph`**:
   - `root`: designated entry module (must exist in `modules`)
   - `modules`: finite set of `GroundModule` nodes (sorted by `name` in canonical serialization)
3. **Deterministic Invariants ($\text{Reduction}_1$, $\epsilon = 0$)**:
   - **Reachability**: Exact set of modules reachable from `root` along directed `imports` edges.
   - **Acyclicity (`has_cycle`)**: Exact cycle detection via Kahn topological peel (`visited_count < module_count`).
   - **Dead Leaves (`dead_leaves`)**: Exact set of unreachable modules (`modules \ reachable`).
   - **Dominators (`dominators`)**: Exact iterative fixed-point dominator sets on reachable nodes: $\operatorname{Dom}(r) = \{r\}$ and $\operatorname{Dom}(v) = \{v\} \cup \bigcap_{u \in \operatorname{Pred}(v)} \operatorname{Dom}(u)$, order-independent across all traversals.
   - **Wrapper AST Classification**: Classifies Lean 4 module text (ignoring `--` comments, `/- ... -/` block comments, blank lines, and `module` header) into:
     - `pure_wrapper`: 1+ `import` statements, 0 declarations outside trivial `export`/`open`,
     - `reexport_hub`: 2+ `public import` statements and 0 proof declarations,
     - `substantive`: contains at least one substantive declaration (`theorem`, `lemma`, `def`, `structure`, `inductive`, `class`, `instance`, `abbrev`).
